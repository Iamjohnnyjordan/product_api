Product API

A Product API built with Python, FastAPI, and SQLite.

The application allows users to create, view, update, and delete products stored in a database. Products include automatically generated part numbers and duplicate product handling.

The project also includes user registration and login with password hashing and JWT authentication. Protected routes require a valid access token before the user can access them.

A basic HTML and JavaScript frontend connects to the FastAPI backend to interact with the product database.

Built With

* Python
* FastAPI
* SQLite
* Pydantic
* JWT Authentication
* HTML
* JavaScript
